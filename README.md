# ReviewerPickerBot

Телеграм-бот, который реагирует на сообщения, содержащие ссылку на `github` или `gitlab` в групповом чате. Бот выбирает двух случайных участников из пула ревьюеров. Участники могут управлять своим участием в пуле с помощью команд.

Если сообщение начинается с `!`, бот его игнорирует.

---

## ✅ Использование

1. Добавьте бота в групповой чат и выдайте ему права администратора.
2. Напишите в чат команду `/start`.
3. Чтобы посмотреть список доступных ревьюеров — используйте `/pool`.
4. Чтобы **выйти из пула**, используйте `/unavailable`.
5. Чтобы **вернуться в пул**, используйте `/available`.
6. Если не хотите, чтобы бот реагировал на ссылку — начните сообщение с `!`.
7. Список всех команд доступен по `/help`.
8. Посмотреть назначенных ревьюеров к последней ссылке — `/info`.

---

## ⚙️ Конфигурация окружения

Создайте файл `.env` в корне проекта со следующим содержимым:

```env
ID=your_api_id
HASH=your_api_hash
TOKEN=your_bot_token
```

## 📤 Примеры сообщений

```text
https://github.com/myorg/myrepo/pull/123
→ Бот выберет 2 ревьюеров из доступных участников.
```

```text
!https://github.com/myorg/myrepo/pull/123
→ Бот проигнорирует это сообщение.
```

---

## 🔒 Приватность

- Бот **не хранит** историю сообщений.
- Хранит только usernames участников из пула.

---

## ℹ️ Примечания

- Бот работает только в **супергруппах**.
- Минимальное количество участников для назначения ревьюеров — **3**.
