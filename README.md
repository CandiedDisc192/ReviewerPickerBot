# ReviewerPickerBot

Телеграм бот, который реагирует на все сообщения, содержащие ссылку, в групповом чате. Можно убрать себя из пулла и возвращение себя в него. Если сообщение в чате начинается с восклицательного знака бот не будет на него реагировать 


## Использование

Добавление бота в чат разработчиков /start

Участники чата, которые по тем или иным причинам не могут ревьювить, прописывают команду  /unavailable 

Разработчик отправляет в чат сообщение, содержащие ссылку на MR.

Бот рандомным образом выбрал двух участников чата на проверку MR и тегнул их.

Если человек стал доступен, чтобы вернуться в пулл ревьюверов он должен прописать команду  /available
